# システム開発 テスト対策サイト（第2〜7回）

システム開発（2026年度後期・水3）のテスト対策用の問題演習サイトです。
Moodle「理解度テスト」1〜12（第2〜7回）と配布スライドをもとにしています。

v3（11/19）で本番の傾向に合わせて調整しました。

- **小テスト原題**：受験レビューの文面・選択肢のまま収録（選択肢の入れ替えや正誤反転はしない）。
- **小テストの記述化**：小テストの選択肢の正しい文や、問題文に書いてあった語句を空欄にして「書かせる」問題。組み合わせ問題は「説明を読んで用語を書く」問題に変換。
- 語句の意味・違いを文章で説明する記述問題は、本番で出ないため外しました。
- 出題形式は「本番想定（同じ論点が選択か書く形で出る）／書く問題だけ／小テストのまま」から選択。
- 予測変換（IME）用の用語リストと、Microsoft IME に読み込めるユーザー辞書ファイルを用意。

閲覧用の共有パスワードで保護された静的サイトです。HTMLは StatiCrypt によりブラウザ内で暗号化されており、パスワードなしでは内容を読めません。
