# システム開発 テスト対策サイト（第2〜7回）

システム開発（2026年度後期・水3）の「2026/11/11 小テスト」対策用の問題演習サイトです。
Moodle「理解度テスト」1〜12（第2〜7回）と配布スライドをもとに、137問（43論点グループ）を収録しています。

- **Moodle原題**：受験レビューの文面・選択肢のまま収録。
- **類似問題**：原題と同じ論点を、短答（用語を書く）・記述・穴埋めに形式変更したもの。
- **スライド由来**：第5回（テスト7・8）など Moodle 原題を確認できていない範囲。
- 出題形式は「ランダム（本番想定）／記述寄り／原題どおり」から選択。ランダムでは同じ論点が選択・短答・記述・穴埋めのどれかで出題され、選択肢の入れ替えや正誤反転（「誤っているものを選べ」）も入ります。
- 記述・短答・穴埋めは段階的なヒント（書く観点 → キーワードの頭文字 → キーワード）を表示できます。
- 記述問題のキーワード判定は目安です（最終判断は模範解答と見比べて自己採点）。

閲覧用の共有パスワードで保護された静的サイトです。HTMLは StatiCrypt によりブラウザ内で暗号化されており、パスワードなしでは内容を読めません。
